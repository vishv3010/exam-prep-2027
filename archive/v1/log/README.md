# Log

## Files

- `daily.md` — one line per day. Blocks done, hours, what was covered
- `mocks.md` — every mock and sectional test, scored
- `gujarati-vocab.md` — the running vocabulary log
- `errors.md` — the error log. **The most valuable file here**

## Daily line format

Keep it to one line. A log you dread writing is a log you stop writing.

```
2026-08-27 | D:1h45 Maths-percentages | L:1h GK-polity | run 25min | guj ✓ | note: ratio still shaky
```

`D` = deep block · `L` = light block

## The error log — read this

Every wrong answer goes in `errors.md` with **why it was wrong**, sorted into one of three:

1. **Didn't know it** — a content gap. Goes back into the syllabus queue
2. **Knew it, misread the question** — an attention problem. Fixed by slowing down on the stem
3. **Knew it, calculation slip** — a process problem. Fixed by working, not by reading

These three need completely different fixes, and lumping them together is why people
re-study material they already know while the real leak goes unpatched.

**Reviewing your error log is worth more per hour than any new chapter.**
Wrong answers are a free, personalised syllabus of exactly what you don't know.
Most people never look at them twice.

## Weekly review — Sunday, 20 minutes

- Hours actually done vs. planned (be honest — the number is for you, not for me)
- Mock score trend
- Top 3 weak topics → they get the next week's deep blocks
- 5 km time, if trialled
